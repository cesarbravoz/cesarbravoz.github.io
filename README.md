# 🚀 César Bravo - Portfolio Web

## 📋 Descripción

Portfolio web personal de César Bravo, Analista de Sistemas y Desarrollador Web especializado en eCommerce, Python, JavaScript y automatización de procesos. Un sitio web moderno con diseño tecnológico y totalmente responsive.

## ✨ Características

- **🎨 Diseño Tecnológico**: Interfaz moderna con efectos holográficos y animaciones CSS
- **📱 Totalmente Responsive**: Optimizado para desktop, tablet y móvil
- **⚡ Rendimiento Optimizado**: Carga rápida y experiencia fluida
- **🔧 Secciones Interactivas**: Hero tecnológico, sobre mí con código Python, habilidades y portafolio
- **🌐 SEO Optimizado**: Meta tags, semántica HTML5 y accesibilidad

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5**: Estructura semántica y accesible
- **CSS3**: Diseño responsive con Flexbox/Grid y animaciones
- **JavaScript**: Interactividad y efectos dinámicos
- **Font Awesome**: Iconografía moderna
- **Google Fonts**: Tipografías Martel Sans y Oswald

### Herramientas de Desarrollo
- **Git**: Control de versiones
- **GitHub Pages**: Hosting y despliegue automático
- **VS Code**: Editor de código principal

## 📱 Responsive Breakpoints

| Dispositivo | Breakpoint | Características |
|------------|------------|----------------|
| Desktop | > 1200px | Layout completo con grid de 3 columnas |
| Tablet | 768px - 1200px | Grid adaptativo, elementos apilados |
| Móvil | < 768px | Navegación hamburguesa, diseño vertical |
| Móvil Pequeño | < 480px | Contenido compacto, fuentes reducidas |
